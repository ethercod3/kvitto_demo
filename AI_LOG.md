# AI log

## Инструменты и модель

- OpenAI Codex (GPT-5) использовался для анализа ТЗ, проектирования, реализации и проверки.
- PDF был извлечен и визуально проверен средствами Poppler, чтобы учесть текст и структуру всех трех страниц.
- Nushell, Git, uv, Ruff и pytest использовались для работы с репозиторием и проверок.

## Ключевые запросы

1. Внимательно прочитать PDF с ТЗ, создать конкретный backlog и включить все бонусы.
2. Инициализировать Git и начать реализацию согласованного backlog.
3. Добавить в Swagger UI автоматическую HMAC-подпись запросов банковского вебхука.

## Предложения пользователя

- Пользователь предложил вынести кастомный HTML Swagger UI из Python-кода в отдельный Jinja-шаблон. По этому предложению страница перенесена в `app/templates/swagger_ui.html`, а Python-модуль оставлен только для настройки и передачи данных шаблону.

## Где предложения ИИ потребовали проверки

- Простая проверка `Idempotency-Key` перед вставкой не защищает от гонки. Поэтому добавлено уникальное ограничение БД и обработка конфликта вставки.
- Стандартный `HTTPException` оборачивает тело ошибки в поле `detail`, что не соответствует требуемому `{"error":"invalid_transition"}`. Для этого ответа используется явный `JSONResponse`.
- Подпись вебхука нельзя считать от повторно сериализованного JSON: пробелы и порядок полей меняют HMAC. Проверка выполняется по исходным байтам HTTP-тела.
